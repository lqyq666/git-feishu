# 重构风险与边界

1. 匿名会话在清除浏览器数据、退出或换设备后无法自行找回；Day 1 完成后的邮箱绑定是跨设备续接的必要步骤。
2. Supabase 中必须启用匿名登录、邮箱提供商、手动身份绑定，并将正式域名加入 redirect allow-list；否则认证会失败。
3. RLS 仅在执行 `supabase/migrations/0001_exploration.sql` 后生效。不要在没有 RLS 的生产表上接入客户端。
4. 飞书公开表单与应用并行期间会产生两套入口。未设计服务端同步前，禁止把同一用户的数据双写到飞书。
5. 没有 CAPTCHA、速率限制和审计策略前，不应公开大规模开放匿名注册。
