# 重构风险与边界

1. 匿名会话在清除浏览器数据、退出或换设备后无法自行找回；邮箱验证码备份是可选但唯一的跨设备续接方式。
2. Supabase 中必须启用匿名登录、邮箱提供商、手动身份绑定，并将正式域名加入 redirect allow-list；否则认证会失败。
3. RLS 需要 `0001_exploration.sql`，Day 2–7 证据类型和推进约束需要 `0002_complete_exploration_loop.sql`；前端部署不能早于对应迁移。
4. 飞书公开表单与应用并行期间会产生两套入口。未设计服务端同步前，禁止把同一用户的数据双写到飞书。
5. 没有 CAPTCHA、速率限制和审计策略前，不应公开大规模开放匿名注册。
6. 草稿保存失败时页面会保留当前输入并显示错误，但关闭页面前仍需用户重试；后续可增加本地双写作为断网保护。
